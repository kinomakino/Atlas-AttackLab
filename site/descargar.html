Todos los retos, en tu equipo

Agentes con herramientas, MCP, RAG y cadena de suministro. Todo corre en Docker, con el modelo incluido. No hay que instalar nada más.

Versión 0.1.0 de pruebas, privada. Para descargar las imágenes hace falta acceso: docker login ghcr.io con un token de GitHub con permiso read:packages.

1. Instala Docker (Docker Desktop en macOS y Windows) y arráncalo.

2. macOS y Linux, en una terminal:

$ curl -fsSLO https://witty-rock-0c004b703.6.azurestaticapps.net/install.sh
$ less install.sh        # léelo antes de ejecutarlo
$ bash install.sh

2. Windows, en PowerShell:

> Invoke-WebRequest https://witty-rock-0c004b703.6.azurestaticapps.net/install.ps1 -OutFile install.ps1
> notepad install.ps1      # léelo antes de ejecutarlo
> powershell -ExecutionPolicy Bypass -File install.ps1

3. El instalador revisa tu equipo, se configura solo y abre el lab. Después tienes el comando atlas-lab (start, stop, status, update, uninstall…).

Comprobar que el instalador es el oficial (SHA-256) 
a0ab47765600c2fc28b1f804cbaaf13f96904fb62e8dc7a6e50c764900268d2a  install.sh
c5a40cbb2c8a7b38c81ef96ca85f03dba5b7996621f4fcbf45f4bc0116403235  install.ps1

También en install.sha256. Con cosign instalado, el instalador verifica además la firma de la imagen.
